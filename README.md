# Smart Home

Современное приложение на Vue 3 для мониторинга и управления устройствами «умного дома» с аналитикой в ​​режиме реального времени.

## Cтэк
- **Vue 3.5+** 
- **TypeScript** 
- **Vite** 
- **Pinia** 
- **Vue Router** 
- **ECharts**
- **Axios** 
- **WebSocket** 
- **Express(для тестов api)** 

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
npm install
npm run dev:all
